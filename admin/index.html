BCCI PHOTO IMPORT

Import photos from BCCI image URLs

Paste one or more BCCI gallery image URLs (one per line). Photos are downloaded by the server and saved inside this website's GitHub repository — not Cloudinary.

REPO STORAGE
Paste plain BCCI URLs or copy a Markdown/table link from ChatGPT, including escaped ampersands. BCCI /_next/image URLs such as w=750&q=75 and direct gallery image URLs are accepted. Max 8 MB per image; duplicate URLs are skipped.
Files are stored at assets/imported-photos/ in this repository.
