# Admin Mobile Navigation

Mobile navigation behavior is implemented in `admin/assets/admin-mobile-nav.js`; the `#admin-mobile-bottom-nav` host is in `admin/index.html`.

- Bottom navigation: `#admin-mobile-bottom-nav`
- Menu toggle: `#admin-mobile-menu`
- Responsive visibility remains controlled by `admin/assets/admin.css`.

The existing script path is intentionally unchanged to avoid breaking Admin Studio. This is a folder boundary/documentation step, not yet an HTML extraction.
