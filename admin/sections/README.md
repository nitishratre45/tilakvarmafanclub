# Admin Studio Sections

Each Admin section has its own folder for its CSS and JavaScript where applicable. Current section markup is still hosted in `admin/index.html`; it has not yet been extracted into independent HTML partials.

- `overview/` — Overview dashboard
- `media/` — Media library
- `gallery-updates/` — Gallery updates
- `videos/` — Video feed
- `news/` — News manager
- `live-updates/` — Live updates
- `repository-health/` — Repository health
- `data-status/` — Data freshness
- `matches/` — Match section
- `stats-death-overs/` — Stats and Death Overs
- `services-security/` — Services and security

Do not mark HTML separation as complete until each section's markup is extracted and the shell loads it safely.
