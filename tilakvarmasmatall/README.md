# Tilak Varma SMAT All Data

This folder is generated by `build_data.py` from the repository's existing source folders:

- `hyd_scoreboards/json/` — Hyderabad SMAT scorecards
- `tilak_varma_commentaries/` — commentary JSON files already filtered/collected for Tilak
- Player ID used: `69845`, verified in the supplied scorecard and commentary samples as Tilak Varma

Generated files:

- `summary.json` — aggregate batting totals and coverage counts
- `matches.json` — match metadata plus Tilak's innings
- `batting_innings.json` — one record per scorecard innings
- `ball_by_ball.json` — commentary delivery records where the batting player ID matches Tilak
- `source_index.json` — references to the original source files

Run from the repository root:

```bash
python tilakvarmasmatall/build_data.py
```

Important: this is a consolidated pack of files currently present in the repository, not a guarantee of complete career coverage. The generated summary reports how many source scorecards/commentary files were found.
